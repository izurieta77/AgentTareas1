# AsturVent — Centro de Comando de Contenido

Pipeline de producción de contenido para Instagram → Sitio web → WhatsApp.
**Todos los prompts maestros (Flow/Veo, Grok Imagine, ChatGPT, Canva) nacen aquí.**

## Cómo usar este repo

1. **Lee primero** `00-FUENTE-DE-VERDAD.md` — datos 100% reales del sitio. Nada fuera de ahí se publica.
2. **Lee** `01-CENTRO-DE-COMANDO.md` — pipeline, reglas de marca, embudo y secuencia de ataque.
3. **Abre el pack** que toque publicar (carpeta `packs/`) y pega cada prompt en su plataforma.

## Embudo (orden obligatorio)

```
Reel/Carrusel (IG)  →  SITIO asturvent-web.netlify.app  →  WhatsApp wa.me/525547977723?text=b2b%20client%20by%20E.Izu  →  «b2b client by E.Izu»
```
El **sitio se promociona primero**; Instagram (`@asturvent`) es secundario. **Nunca se menciona precio.**
